## 2. 逐步操作 + 可直接复制的文案

### ① 编译自检（开发者工具）

1. 用微信开发者工具「导入项目」，目录选 `baking-cost-miniprogram`，appid 自动带出。
2. 点顶部「编译」，确认 Console **零报错、零红字**。
3. 重点切一下手机的深色/浅色模式各看一遍（`app.json` 开了 `darkmode: true`），确认文字没有看不清。

### ② 真机预览（开发者工具 → 预览）

扫码后在手机上按这条路径走一遍，**这是审核员拿不到测试数据时唯一能验证的东西**：

| 验什么 | 怎么验 | 期望 |
|---|---|---|
| 本地存储 | 原料页加一个原料 → 完全退出小程序 → 重进 | 数据还在 |
| 成本核算 | 商品页加商品、选原料填用量 | 成本/毛利/建议售价自动算出 |
| 长图保存 | 经营报表页 → 导出本月长图 → 保存到相册 | 弹授权，同意后相册里有图 |
| 配方手册 | 商品页顶部「配方手册 ›」进入 | 两个视图都能切换 |

### ③ 上传代码（开发者工具 → 上传）

- **版本号**：`1.0.0`（首次发布）
- **上传备注**：（直接复制）

```
首次发布：本地烘焙成本核算工具。支持原料/配方管理、成本与建议售价自动核算、按日销量记录、经营报表与长图导出。纯本地存储，无网络请求。
```

> 上传成功后，代码进 mp 后台「管理 → 版本管理 → 开发版本」。

### ④ 提交审核（mp.weixin.qq.com）

进入「管理 → 版本管理 → 开发版本」，点「提交审核」，按下面填：

**服务类目**（一级 → 二级）：
```
工具 → 效率
```
> 备选「工具 → 信息管理」。**不要选金融/商业服务**，会触发额外资质要求，平白卡住审核。

**功能描述 / 测试说明**（直接复制）：

```
本小程序是面向私房烘焙、小型工作室的本地成本核算工具，全部数据仅存于用户手机本地，不上传服务器、不收集个人信息。

功能页面：
1. 记销量：按日期记录各商品当日销量，查看当日收支与毛利。
2. 原料：录入原料进价、重量、采购单位，自动折算每克单价。
3. 商品：为商品配置配方（选原料 + 用量），自动核算材料成本、损耗、毛利与建议售价；顶部入口可进入「配方手册」按商品/按原料双向查看。
4. 经营报表：查看净利润、营收构成、商品排行、毛利率健康、固定支出，可导出长图分享。
5. 数据备份：导出/导入本地数据，防止换机或卸载导致数据丢失。

体验路径（数据为本地存储，首次打开为空属正常）：
进入「原料」→ 添加任意原料（填名称、进价、重量）→ 进入「商品」→ 添加商品、设售价、选原料填用量 → 进入「记销量」记录一笔 → 进入「经营报表」查看数据并导出长图。

权限说明：仅在用户主动点击「导出长图」时申请保存到相册权限（scope.writePhotosAlbum），用于保存图片，不用于其他用途。
```

**测试账号**：无需（纯本地存储，无登录体系）。此项若必填，填「无需账号，直接打开即可体验」。

**页面路径**：如实填写 5 个页面，尤其带上 recipe：

```
pages/daily/daily
pages/material/material
pages/goods/goods
pages/monthly/monthly
pages/recipe/recipe
```

### ⑤ 用户隐私保护指引（mp 后台 → 设置 → 服务内容声明）

2023 年 9 月后强制配置，**不配会影响审核**。按下面声明：

```
本小程序不收集用户个人信息，不上传任何数据到服务器。

本地存储：使用 wx.setStorageSync 在用户设备本地保存用户主动录入的经营数据（原料、商品配方、销量、固定支出、参数设置），仅用于本机计算与展示成本、毛利、报表，用户可通过「经营报表 → 数据备份」自行导出或清除。

相册权限：仅在用户主动点击「导出长图」时申请 scope.writePhotosAlbum，用于将生成的图片保存到用户相册，不读取相册内容。

不涉及：位置信息、麦克风、摄像头、通讯录、 getUserProfile/getUserInfo、第三方 SDK、网络请求。
```

> 在指引表单里，「收集的信息类型」如必选，勾选「无」或最接近的「设备信息中的本地存储」；「使用目的」填「本地保存用户录入的经营数据，不上传」。

### ⑥ 发布上线（审核通过后）

- 建议先**灰度发布 10%** 观察 1 天，无异常再全量。
- 发布后确认：5 个页面都能打开、recipe 入口能从商品页进入、长图导出可用。

## 3. 本项目 4 个专属检查点

| 检查项 | 等级 | 说明 |
|---|---|---|
| 保存相册授权 | 🔴 | 代码用了 `wx.saveImageToPhotosAlbum`，审核员点导出会遇到 `scope.writePhotosAlbum` 弹窗。功能描述里已写明「主动点击才申请」，避免被判「强制授权」 |
| 纯本地无需服务器 | 🟢 | 无 `wx.request`，不用配合法域名、不用备案、不用 HTTPS 证书，审核更快 |
| 深浅主题双验 | 🟡 | `darkmode: true`，预览时切深色/浅色各看一遍，长图尤其注意 |
| recipe 页入口 | 🟡 | recipe 不在 tabBar，提交审核时页面路径要带上 `pages/recipe/recipe`，功能描述里已写明入口 |

## 4. 一个最容易卡审核的点

审核员拿到小程序时**本地存储是空的**，他会看到空页面。本项目各页空态已有引导文案：

- 记销量：「今天还没记录销量，点右上『+ 添加商品』从商品库选择。」
- 原料：「先点下方『+ 添加原料』…」
- 商品：「点下方按钮添加第一个商品，设好售价并选原料…」
- 配方手册：「还没有商品 / 还没有原料」

只要测试说明里给了体验路径（上面已拟好），审核员应能理解这是干嘛的。
